# The Great One — Web3 Portfolio

A premium, animated React/Vite landing page built around the supplied proof-of-work assets.

## Stack
- React + Vite
- Framer Motion
- Lucide React
- Custom CSS animations
- Responsive mobile layout

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Content
- Hero with animated Web3 orbit
- Shining text and glow effects
- About section
- Experience timeline
- Proof-of-work project cards
- Full project gallery modal
- Ecosystem logo cloud
- Contact section with email-copy interaction
- X and Telegram links

## Personalization
Main content is in `src/main.jsx`.
Visual tokens and animations are in `src/styles.css`.
All supplied images are already placed in `public/assets/`.

The implementation is self-contained and does not require a React Bits Pro license to run.
